## Separation from baseline

- Step 3 models the validated developer-plan shell only.
- The proposed office conversion, cabinetry, coffee station, laundry/storage, furniture, finishes and lighting stay outside the Step 3 shell.
- Furniture-elevation dimensions are not used to infer wall locations, opening sizes, ceiling height or construction feasibility.
- Page 7's 2.60 m height is a joinery/elevation proposal, not a verified apartment ceiling measurement.

## Conflicts and uncertainties

1. The proposal intentionally changes room use and adds millwork; it does not document which existing walls/openings are retained or altered with survey precision.
2. Several depth annotations appear to use `cm` where the numeric magnitude looks like metres. They must be confirmed before furniture modeling.
3. The proposal is described by the user as mostly, but not completely, intended for implementation. Each proposed element therefore remains independently switchable and pending approval.
4. No proposed render is used as evidence for hidden shell conditions, balcony access operability, wall thickness, sill/head height or ceiling/bulkhead geometry.
